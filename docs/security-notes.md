# Security Notes

This repository was created as a sanitized public portfolio case study.

## Excluded From Public Repository

The following items are intentionally excluded:

- Google Apps Script source code
- API tokens
- Tenant URLs
- Organization names
- Sheet IDs
- Report IDs
- Internal hostnames
- Device names
- Usernames
- Raw endpoint data

## Safe Public Content

This repository only includes:

- Project overview
- Sanitized screenshots
- Architecture summary
- Security notes
- Project summary

## Why Source Code Is Private

The source code contains API integration logic and operational workflow details that should not be exposed publicly.

## Recommended Security Practices

- Store secrets outside code
- Use least-privilege API tokens
- Rotate exposed credentials immediately
- Redact tenant-specific values
- Avoid uploading raw operational data
- Review screenshots before publishing
