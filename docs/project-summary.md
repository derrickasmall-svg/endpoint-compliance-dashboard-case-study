# Project Summary

This project demonstrates an endpoint compliance reporting workflow that automates data collection from an endpoint management platform and publishes summarized results into Google Sheets dashboards.

## Problem

Security and infrastructure teams often need recurring visibility into endpoint compliance, agent health, operating system migration status, VPN client versions, and device control enforcement.

Manual reporting is time-consuming and inconsistent.

## Solution

The automation collects compliance data through an API, summarizes the results by control area, and writes the output into dashboard-style Google Sheets tabs.

## Business Value

- Reduces manual reporting effort
- Improves visibility into endpoint compliance
- Tracks security control adoption over time
- Supports vulnerability and infrastructure management decisions
- Provides executive-friendly reporting
