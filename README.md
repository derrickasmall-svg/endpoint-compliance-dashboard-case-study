# Endpoint Compliance Dashboard Automation

## Overview

This project is a portfolio case study for an endpoint compliance dashboard automation workflow that collects endpoint security and compliance data, summarizes results, and presents the information in Google Sheets dashboards.

Source code, organization-specific details, API tokens, tenant URLs, report IDs, and internal identifiers are intentionally excluded.

## Key Features

- Automated endpoint compliance reporting
- Security agent version compliance tracking
- Security service health reporting
- VPN client version compliance reporting
- Endpoint management client coverage reporting
- USB device control policy reporting
- Windows 11 upgrade progress tracking
- Historical trend reporting
- Google Sheets dashboard visualization

## Technologies Used

- Google Apps Script
- Tanium Gateway API
- GraphQL
- Google Sheets
- JavaScript
- Endpoint security reporting
- Compliance automation
- Dashboard visualization

## Security and Privacy

This repository does not include:

- Source code
- API keys or tokens
- Tenant URLs
- Organization names
- Internal hostnames
- Report UUIDs
- Sheet IDs
- Usernames
- Device names
- Sensitive operational data

All screenshots are sanitized and use generalized labels suitable for portfolio review.
